# Niamh 跳跃姿势预览 v6

日期：2026-11-14。状态：离线动作草稿，未在 Unity 验证。

依据用户标注（`references/`）：腾空时双腿向后、手臂向前，起跳抬头；落地时轻微低头。手、腿、头与身体的动作使用同一个平滑腾空节奏，落地低头与 v5 的轻微下沉同步并归位。

素材直接来自 v5 的 `_m` 部件，源 PSD 快照为 `Niamh_user_revision_source.psd`。本轮没有重切或补画。动画源为 `tools/render_preview.py`，参数写入 `motion_preview_spec.json`。

`previews/Niamh_motion_v6.gif` 为四格同步预览；`previews/jump_pose_check.png` 展示上升、最高点、下落、着地、复位五个时刻。腾空姿势的近侧和远侧腿最多分别向后旋转约 19° 和 30°，手臂向前约 30°，头向上约 6°，落地向下约 5°；实际效果还受到身体轻微前倾影响。预览内部画布上方扩大留白，避免跳到最高点时裁掉头发，同时保留原有地面位置。

远侧腿仍由近侧素材派生，肘膝与衣物形变仍是简化效果；在真实场景、控制器和 Play Mode 下尚未验证。
