# Niamh 落地调整预览 v5

日期：2026-11-14。状态：离线预览，尚未在 Unity 中验证。

用户希望落地压缩减小，让相关部件轻微位移后复位。本版使用 v4 从用户 `_m` 文件直接导出的部件，没有重切或覆盖原图。

落地时间为跳跃循环的 1.25–1.55 秒。使用平滑曲线，身体和后发最多下移 3 像素，头和手臂最多下移 4 像素，后发向后、手臂向前各最多偏移 1 像素，随后归位。腿和靴子保持落地点；落地期间不缩放整个人物。起跳预备压缩由 7% 减为 2%，让跳跃两端的幅度更协调。

`previews/Niamh_motion_v5.gif`：待机、走、跑、跳跃落地四格同步；`previews/landing_check.png`：落地开始、下沉最深、恢复的三帧。`tools/render_preview.py` 与 `motion_preview_spec.json` 保存实际动画参数。

本版只验证了离线 GIF 与部件衔接。实际游戏速度、角色和场景的比例、Unity 动画切换和 Play Mode 仍待验证。
