## 新对话先做什么

1. 先读 `STORYBOARD_RESUME.md` 与 `TechnicalArt/妮芙双手捧十字架动作参考_2026-11-16.md`；以上路径相对仓库根目录。
2. 用原游戏角色 `../Niamh_side_static_v3.png` 与用户修订源稿核对胸前系带/饰件、领口、衣褶、披风开口、袖口与纹样，逐项保留。十字架沿用游戏资产。
3. 先修一张胸前捧持静帧：两条手臂都能追到合理的肩、肘、腕；恰好两只手。每手最多五指，握持时依遮挡减少可见指，不在握柄后拼出一排悬空指头。远手可大部分被近手遮住。
4. 修正后先做全身与手部放大对照。检查通过后再做中段、高举、分层和离线动画；不能沿用本目录已退回的错误部件。
5. 用户原有 WIP 拆件 PSD/PNG 保持原件。当前没有新的可用分层部件、离线 GIF 或 Unity 接入。
