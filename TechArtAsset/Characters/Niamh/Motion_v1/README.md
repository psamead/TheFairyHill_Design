# Niamh 动作预览 v1

日期：2026-11-14。用途：让项目负责人查看现有村庄与森林小径所需的基础动作。状态：离线动作草稿，尚未用户确认、尚未接入 Unity。

## 看什么

`previews/Niamh_motion_v1.gif` 为四格同步预览：待机、走、跑、跳跃与落地。中性绿色背景仅用于检查部件衔接，不代表实际游戏场景或最终灯光。

使用现有 `../Niamh_side_static_v3.png`，保留原图 325×698 像素坐标。头部按用户 2026-11-14 提供的轮廓参考拆分，并保留领口重叠。两个原始标注截图保存在 `references/`；轮廓实际执行点保存在脚本中。

## 编辑源与复现

- `Niamh_puppet_trial_v1.psd`：Photoshop 分层源文件，包含原始参考和拆件；完整原始参考隐藏，部件可单独调整。
- `parts/`：Photoshop 导出的等画布透明 PNG，位置没有自动居中或裁到内容边缘。
- `tools/split.jsx`：在 Photoshop 2023 中执行的拆件脚本。先前试验使用复制粘贴会使选区居中；本版使用复制原图层再清除选区外内容，保留原始坐标。
- `tools/render_preview.py`：Pillow 13 离线合成动画，不修改 Unity。运行 `python tools/render_preview.py` 重新导出预览。
- `motion_preview_spec.json`：枢轴、时长和当前限制；渲染脚本为本轮姿势计算的实际依据。

## 当前限制

这是一版便于看运动的简化纸偶：裙摆与披风仍为整体，远侧腿来自近侧素材，手臂暂未分肘关节，身体上原前臂位置使用平涂修补。头发未单独绑定。脚步、接缝、服装形变和左右翻转仍须结合动画检查与实际场景尺度继续调整。

PSD 保存和 PNG 导出已完成；PSB 分层导入、Unity 动画切换、真实移动速度匹配、碰撞体保护和 Play Mode 均未验证。不要把此目录当作已完成的 Unity 接入交付。后续动作通过审阅并完成素材检查后，再编写另一台电脑 Codex 的接入任务。
