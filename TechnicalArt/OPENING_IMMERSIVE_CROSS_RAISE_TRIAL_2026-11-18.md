## 界面试装规则

| 项目 | 本轮行为与依据 |
| --- | --- |
| 画面 | 参考守灯人的全屏故事画，保持比例覆盖屏幕；取消原图框、字幕分隔线和页码。画面是已批准占位图，人物画风仍待后续完善。 |
| 字幕 | 置于画面下方柔和渐暗区域，象牙白与阴影提升对比；每帧可单独调整归一化字幕区域，避免遮脸。当前三条字幕和6/7/6秒时长不变。 |
| 导航 | 轻量 Next/Skip 位于右上安全区，右下显示 Space / Enter / Esc。保留原章节卡、过渡、重复输入防护、切关遮罩及按键释放保护。 |
| 按键可读性 | 按键字母或名称下加线。覆盖开场导航、游戏操作栏、动态交互/消息；普通英文词不加线。当前字体不含下划线字形，用 TMP 字形位置绘制独立 UI 线，保留共享字体资产。 |
| 回退 | `OpeningSequencePlayer.storybookLayout=false` 使用原布局；停止运行后调整 Inspector 选项再重新进入开场。 |

这里借鉴守灯人的界面结构和阅读方式，不复制它的夜间色调、剧情、任务范围或游戏数值。章节卡继续用既有独立大标题。

## 举高动作与红障碍

| 项目 | 当前接法 |
| --- | --- |
| 动作选择 | B：当前 v8 → 用户原画举高姿势 → 恢复 v8，无胸前中间姿势。所有旧 GIF 和两份用户 PSD 保留。 |
| 触发 | 保持现有有铁十字架、附近存在受控荆棘墙、Q触发的条件与范围；这是当前已有终段事件的表现接入。 |
| 持势与反馈 | 沿用墙体原0.3秒红光淡出与1.6秒消解，持势覆盖这1.9秒，暂时停止水平与跳跃输入；物理和碰撞照常。具体手感待实机检查。 |
| 对齐 | 当前动作350×699、100 PPU；自定义 pivot `(163.5,0)` 像素，与327×699基础角色相同。不能简单改为新画布的底部中心，否则会产生横移。 |
| 恢复与备用 | 举高时隐藏原六部件，结束恢复原可见状态；禁用时清理覆盖层。姿势资源缺失时警告并保留原墙体逻辑。 |

本轮沿用既有墙体的光效、火花和消解。设计允许第二动作将来承担大型剧情光束，但本轮没有实现新大光束。胸前动作仍供小怪、小障碍和小剧情使用，不因此新增普通战斗系统、伤害、冷却或解锁规则。离线GIF的2秒循环不作为游戏冷却或墙体时序。
