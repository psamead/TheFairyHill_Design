# 妮芙 Niamh 拆件与骨骼清单（v1，2026-10-17）

> 基准图：`MJ_ref/Niamh_v3_turnaround.png` 的**朝右侧面**（第 2 个人物）。正面 / 背面只作造型参考。
> 用途：在 Photoshop 拆件为 PSB → Unity 2D Animation + PSD Importer 绑骨骼 → 做待机 / 走 / 跑 / 跳试验，估算每个角色的工时。
> 游戏内只做朝右一套，朝左在 Unity 里 `flipX`。

## 1. 文件与尺寸

| 项目 | 规格 |
|---|---|
| 文件 | `TechArtAsset/Characters/Niamh/Niamh_rig.psb`（必须存 **.psb**，PSD Importer 只吃 PSB 的分层导入最稳） |
| 画布 | 人物高约 **440 px**（游戏内屏幕高 200–220 px，部件按 2 倍绘制）；四周各留 40 px 透明边 |
| 颜色 | RGB 8 bit，透明背景，不要背景层 |
| PPU | 100（Unity 导入时设置），游戏内再按需要缩放 |

做法：从 turnaround PSD 里把朝右侧面盖印成一层 → 裁出 → 缩放到人物高 440 px → 新建 PSB 粘贴进去 → 按下表逐个部件抠出成独立图层。被遮住的地方要**补画**（见第 4 节）。

## 3. 骨骼与枢轴点

| 骨骼 | 父级 | 枢轴位置 | 绑定的图层 |
|---|---|---|---|
| `root` | — | 两脚之间的地面 | — |
| `hip` | root | 腰带中心 | skirt, satchel |
| `spine` | hip | 腰带上方 | torso, cross, cape_front, cape_back |
| `neck` | spine | 领口 | — |
| `head` | neck | 下巴后方、脖子顶端 | head, eye, circlet, hair_front |
| `hair_1` → `hair_2` → `hair_3` | head | 后脑 → 肩 → 腰 | hair_back_1/2/3（链式，做飘动） |
| `cape_1` → `cape_2` | spine | 肩 → 披风中段 | cape_front 下摆、cape_back |
| `shoulder_L` → `elbow_L` → `wrist_L` | spine | 肩 / 肘 / 腕 | arm_upper_L / arm_lower_L / hand_L |
| `shoulder_R` → `elbow_R` → `wrist_R` | spine | 同上 | 远侧手臂 |
| `thigh_L` → `knee_L` → `ankle_L` | hip | 髋 / 膝 / 踝 | leg_upper_L / leg_lower_L / boot_L |
| `thigh_R` → `knee_R` → `ankle_R` | hip | 同上 | 远侧腿 |

共约 **22 根骨骼**。腿和手臂加 IK（Unity `2D IK` → Limb Solver）。

## 4. 拆件注意

1. **重叠区要补画**：每个会转动的关节（肩、肘、髋、膝），上下两段各多画 10–15 px，否则动起来会露缝。
2. **被遮挡的地方要补画**：手臂后面的身体、头发后面的后脑、披风后面的裙子。没有画板的话，用仿制图章 + 涂抹工具补出大色块就够，游戏里看不清细节。
3. **远侧肢体压暗**：远侧的手臂和腿整体调暗约 10%，制造前后层次。
4. **配件独立**：十字架、挎包、手绳各自一层，方便以后做「断绳 / 新系」两种状态的十字架。

## 5. 试验动画与工时记录

| 动画 | 帧长（建议） | 关键姿势 | 记录实际耗时 |
|---|---|---|---|
| idle 待机 | 1.5–2 s 循环 | 呼吸起伏、头发 / 披风轻摆 | |
| walk 走 | 0.8 s 循环 | 4 个关键姿势：接触 / 下沉 / 经过 / 抬起 | |
| run 跑 | 0.5 s 循环 | 身体前倾，头发和披风大幅后飘 | |
| jump 跳 | 起跳 / 滞空 / 下落 / 落地 4 段 | 落地有压缩 | |

工时 = 拆件 + 绑骨 + 4 个动画的总时长，用来估算奥伊芯、贵族等其他角色。
