## 3. 本轮写提示词学到的事
| 观察到的现象 | 本轮做法与证据 | 适用范围 |
|---|---|---|
| 写成“从丘脚看”后丘占满画面 | 改为隔着草地平望，在中景描述完整丘体及左右坡脚；BG02 r02 → r03 | 位置与尺度描述比笼统的 wide 更具体 |
| 同时想改丘形与笔触，整图生成的构图不断漂移 | 保留 r03 U4 及红线，另给合成丘形导稿；r06 仍出现放大和重叠 | 图像提示只能引导构图，需逐张核对 |
| 三色导稿的亮边像连续色带 | 改写为金光在短草处断开、坡脚草色接入田面；另用 OP01 草坡作风格参考 | 导稿的几何形状与绘画质量分开评审 |
| 近草笔触传到云、远丘和田界，单图显得过重 | 区分前景尖细草笔、中景明暗面、远景近明度灰绿色块和薄云；四宫格后必须看单图 | 取样局部用于它实际包含的内容 |
| Editor 擦去整座小丘后，四张回图都补成平地或远坡 | 保存 mask、实际正文和回图；后续拟用导稿留住丘形 | 本次 V7 编辑失败，原因未隔离，其他模型需另测 |
| 外部合成图上传与 URL 载入均报错 | 归档失败反馈，改走 Discord 图像提示 | 仅记录本次入口失败，不能推为 MJ 永久不支持上传 |
| OP02 两轮正面摆姿，第三轮略向右转 | 正文先写停止、肩头与目光方向，再写衣装；第三轮准备稿 cw 100 → 40 | 回图未带参数，cw 数值效果尚未独立证实；衣装仍有漂移 |
| 小墓门被生成为陡崖或墓碑 | 改写为连续草皮的低土丘、坡脚小暗缝；后两轮恢复土丘 | 门缝与冷光尚未形成可验收细节 |
| 媒体链接读取返回 403 | 按负责人标注记录参考对应，并与本地原图核对文件名；保存本地副本 | 链接可失效，记录不可只依赖 CDN |
