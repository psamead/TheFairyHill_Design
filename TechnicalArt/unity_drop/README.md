# Unity 美术素材临时交接区

当 Unity 工程里没有任务所需素材时，由维护者把**获准交付的副本**放入此处的独立任务文件夹，再通过双方可访问的共享网络目录通知 Unity 制作端。

## 使用约定

- 每项任务使用 `YYYY-MM-DD_TaskName/` 子目录；只放该任务明确需要的文件和一份简短 `README.md`。
- README 记录来源仓库相对路径、文件版本/尺寸/格式、目标 Unity 目录、交接日期和用途。不得把原始 PSD、个人资料或未批准素材放在临时区。
- Unity 端只复制，不移动、删除或改写这里的文件；完成后在 Unity 任务记录中注明复制清单。
- Unity 已预置所需文件时直接使用工程内版本，无需再复制到此处。GitHub 不是默认素材传输渠道。
- 网络盘符及主机名依机器配置而异，交接文件只写仓库相对路径。
