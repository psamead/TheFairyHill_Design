## 后续归档规则

- 游戏截图、录屏和用户标注放本目录，按日期与修改轮次建立子目录；编号后保留简短内容名。该轮README写清来源、截图日期、归档日期、版本和待确认项。
- 从Unity端复制，不移动或覆盖源图；保持原生尺寸和像素。重命名时保留原名对应关系，需要时记录SHA256。裁切、标注或缩图另存，并说明它们是衍生图。
- 区分用户实际操作、工具模拟输入、原生截图与参考／占位图；截图存在不等于完整人工路线、声音、性能或用户认可通过。
- 可在同轮目录保留反馈报告与结果清单。原始Console／驱动脚本留Unity证据目录，README提供来源路径。
- Word／PDF排版检查图继续放对应文档QA目录，美术候选继续放素材／参考目录，不混入游戏实机截图。

与守灯人采用相同的按日期／主题归档原则；本项目沿用既有拼写 `ForDesignScreenShot`，守灯人沿用 `ForDesignScreenshot`，不为统一大小写另建目录。
